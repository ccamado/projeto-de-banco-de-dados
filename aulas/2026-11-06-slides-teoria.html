DDL versus LMD

DDL: estrutura — CREATE TABLE, ALTER TABLE.
LMD: dados — INSERT (inserir), SELECT (consultar), UPDATE (alterar), DELETE (excluir).

Resumo para o caderno

Banco relacional possui tabelas, linhas (registros) e colunas (atributos). PK identifica e FK relaciona. DDL define a estrutura; LMD manipula registros. INSERT inclui, SELECT consulta, UPDATE altera e DELETE exclui. Seleção filtra linhas com WHERE; projeção escolhe colunas com SELECT. Use WHERE para não modificar registros indevidos.
