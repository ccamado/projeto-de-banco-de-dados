1. Das regras para a documentação

Já descobrimos que os dados precisam obedecer regras. Agora precisamos registrar essas decisões.

Se uma regra ficar apenas na memória de uma pessoa, outras equipes podem entender o campo de outra maneira. Um documento comum ajuda todos a trabalhar com os mesmos significados.

Dicionário de Dados

Documento que explica os campos de um sistema e registra as regras definidas para eles.

2. O que registrar

Para começar, nosso Dicionário de Dados terá cinco informações:

  • Campo: nome usado para reconhecer o dado.
  • Significado: o que aquele campo representa.
  • Tipo esperado: número, texto, data, horário ou sim/não.
  • Obrigatório? informa se o preenchimento é necessário.
  • Regra: condição que o valor deve respeitar.

  1. Qual coluna explica o que o campo representa?
  2. Em qual coluna registramos que um valor não pode ficar vazio?
  3. Por que duas equipes precisam usar os mesmos nomes?

Importante: hoje não vamos completar todos os campos. Estamos praticando como documentar decisões.

5. DER e Dicionário: funções diferentes

DER

Mostra visualmente a estrutura: entidades e atributos.

Dicionário

Explica os dados e registra suas regras.

Os dois materiais devem concordar nos nomes e nos campos, mas cada um comunica uma parte diferente do projeto.

Resumo para o caderno

DICIONÁRIO DE DADOS

Documento que registra informações sobre os campos de um sistema.

Para cada campo podemos registrar:

  • significado;
  • tipo esperado;
  • obrigatoriedade;
