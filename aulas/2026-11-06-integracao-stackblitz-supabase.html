Resumo para copiar no caderno

Projeto de Banco de Dados — 06/11/2026
Um banco relacional organiza dados em tabelas com linhas (registros) e colunas (atributos). A chave primária (PK) identifica cada registro; a chave estrangeira (FK) relaciona tabelas. DDL define estruturas, por exemplo CREATE TABLE. SQL LMD manipula dados: INSERT inclui, SELECT consulta, UPDATE altera e DELETE exclui. Na álgebra relacional, seleção escolhe linhas que atendem a uma condição (como WHERE ativo = true); projeção escolhe colunas (como SELECT titulo, descricao). Antes de alterar ou excluir registros, devemos conferir a condição WHERE. Na Central de Avisos, essas operações permitem cadastrar, consultar, atualizar e remover comunicados.

Entrega, critérios e plano B

Entregar: dois arquivos SQL (consultas e CRUD), ao menos duas evidências dos resultados sem dados pessoais e respostas: (1) seleção x projeção; (2) DDL x LMD; (3) por que WHERE evita alterações indevidas?

Critérios: execução e resultados 40%; compreensão/explicação 30%; segurança/uso correto de WHERE 20%; organização 10%. A entrega não comprova aula ministrada até confirmação docente.
