DER de referência — 5 tabelas e 4 relações 1:N

O modelo lógico orienta a criação das tabelas. Para visualizar as ligações no Supabase, as FKs precisam ser declaradas.

USUARIO🔑 id_usuario (PK)nometipo
CATEGORIA🔑 id_categoria (PK)nome
TURMA🔑 id_turma (PK)nome
AVISO🔑 id_aviso (PK)titulo · data_aviso🔗 id_usuario (FK)🔗 id_categoria (FK)
AVISO_TURMA🔑🔗 id_aviso (PK/FK)🔑🔗 id_turma (PK/FK)
USUARIO 1 → N AVISOCATEGORIA 1 → N AVISOAVISO 1 → N AVISO_TURMATURMA 1 → N AVISO_TURMA

AVISO N ↔ N TURMA: relação resolvida pela tabela associativa AVISO_TURMA, com chave primária composta (id_aviso, id_turma).

01 — DDL completo

-- CEPEF 2A | 30/10/2026 | demonstração em projeto de teste
-- Executar uma vez, preferencialmente num projeto Supabase vazio.
CREATE SCHEMA IF NOT EXISTS central_avisos_demo;
CREATE TABLE central_avisos_demo.usuario (id_usuario INTEGER PRIMARY KEY, nome VARCHAR(100) NOT NULL, tipo VARCHAR(30) NOT NULL);
CREATE TABLE central_avisos_demo.categoria (id_categoria INTEGER PRIMARY KEY, nome VARCHAR(60) NOT NULL UNIQUE);
CREATE TABLE central_avisos_demo.turma (id_turma INTEGER PRIMARY KEY, nome VARCHAR(20) NOT NULL UNIQUE);
CREATE TABLE central_avisos_demo.aviso (
 id_aviso INTEGER PRIMARY KEY, titulo VARCHAR(150) NOT NULL, data_aviso DATE NOT NULL,
 id_usuario INTEGER NOT NULL REFERENCES central_avisos_demo.usuario(id_usuario),
 id_categoria INTEGER NOT NULL REFERENCES central_avisos_demo.categoria(id_categoria)
);
CREATE TABLE central_avisos_demo.aviso_turma (
 id_aviso INTEGER NOT NULL REFERENCES central_avisos_demo.aviso(id_aviso),
 id_turma INTEGER NOT NULL REFERENCES central_avisos_demo.turma(id_turma),
 PRIMARY KEY (id_aviso,id_turma)
);

03 — Consultas demonstrativas

-- Só para demonstração dos resultados; SELECT/JOIN serão estudados depois
SELECT a.id_aviso,a.titulo,u.nome AS responsavel,c.nome AS categoria
FROM central_avisos_demo.aviso a
JOIN central_avisos_demo.usuario u ON u.id_usuario=a.id_usuario
JOIN central_avisos_demo.categoria c ON c.id_categoria=a.id_categoria
ORDER BY a.id_aviso;
SELECT a.titulo,t.nome AS turma
FROM central_avisos_demo.aviso_turma at
JOIN central_avisos_demo.aviso a ON a.id_aviso=at.id_aviso
JOIN central_avisos_demo.turma t ON t.id_turma=at.id_turma
ORDER BY a.id_aviso,t.id_turma;
