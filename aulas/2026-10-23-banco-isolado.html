23/10/2026 — Projeto de Banco de Dados

2º A · CEPEF · 1º, 2º e 4º tempos · Prática no próprio Supabase de cada aluno

Missão: banco isolado da Central de Avisos

Você vai criar do zero um esquema chamado cepef_pratica, com três tabelas relacionadas: categorias, turmas e avisos. Em seguida, vai inserir dados fictícios e executar consultas e testes de integridade.

Atenção: use apenas o SEU projeto Supabase. Nunca execute esses scripts no projeto de outro colega ou em banco de produção. O script 02 apaga e reinsere somente os AVISOS desse esquema didático para reiniciar o exercício.

1. ABRIR MEU SUPABASE →

Scripts em ordem de execução

Abra cada arquivo, use o botão de copiar do GitHub e cole no SQL Editor do Supabase. Execute um por vez.

1. Criar esquema e tabelas →2. Inserir dados fictícios →3. Consultas SELECT e JOIN →4. Testar INSERT, UPDATE e DELETE →5. Nota para integração futura (não executar agora) →

O quinto arquivo é apenas uma nota de preparação: não habilita acesso público.

Divisão dos três tempos

  1. 1º tempo (50 min): identificar schema/tabela/chave primária/chave estrangeira; executar script 01, verificar três tabelas em cepef_pratica; executar script 02 e verificar oito avisos.
  2. 2º tempo (50 min): executar script 03, interpretar filtragem, ordenação e dois JOINs; resolver o desafio de listar somente os avisos ativos de uma turma.
  3. 4º tempo (50 min): executar script 04 e observar INSERT, UPDATE, DELETE e ROLLBACK; entregar capturas e respostas explicativas.

Desafios e evidências

  1. Quais são as três tabelas criadas? Identifique as duas FKs de avisos.
  2. Quantos avisos foram inseridos? Quantos aparecem ativos na turma 2A?
  3. Explique por que o JOIN usa o ID das tabelas relacionadas.
  4. Qual a diferença entre desativar um aviso e excluí-lo?
  5. Faça uma consulta própria ordenada pelo título e mostre o SQL e o resultado.

Entrega: arquivo de consultas .sql, 2 capturas do SQL Editor mostrando resultados sem dados pessoais e respostas curtas aos desafios. Critérios: execução 40%, interpretação 30%, evidências 20%, organização 10%.

Sem internet: desenhe as três tabelas e as chaves; simule em papel os oito registros e o resultado das consultas.
